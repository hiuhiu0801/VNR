# August 1945 image archive

Folder này chỉ còn là ghi chú chuyển tiếp. Ảnh đang dùng trong UI đã được tách lại như sau:

- `public/images/phases/`: ảnh nền riêng cho từng giai đoạn.
- `public/images/session8/`: ảnh các mốc giai đoạn chuẩn bị lực lượng.
- `public/images/session9/`: ảnh các mốc giai đoạn chớp thời cơ.
- `public/images/session10/`: ảnh các mốc giai đoạn giành chính quyền.
- `public/images/session11/`: ảnh các mốc giai đoạn bảo vệ thành quả.

Không đặt ảnh đang render cho session vào folder này nữa, để tránh trộn ảnh nền giai đoạn với ảnh mốc then chốt.
